# ✊✋✌️ Rock Paper Scissors Game

A simple and fun **Rock Paper Scissors game** built using HTML, CSS, and JavaScript. Play against the computer, set your own target score to win, and enjoy a confetti celebration animation when you win!

## 📌 Features
- 🗿📄✂️ Play Rock, Paper, or Scissors against the computer
- 🎯 Set a custom target score before starting the game
- 📊 Live scoreboard showing Player, Computer, and Tie counts
- 🎉 Confetti celebration animation when the player wins
- 😢 Game Over screen when either player or computer reaches the target score
- 🔄 Reset button to restart the game anytime

## 🛠️ Tech Stack
- **HTML** – Page structure
- **CSS** – Styling and layout
- **JavaScript** – Game logic, score tracking, and confetti animation using the Canvas API

## 📂 Project Structure
```
index.html   → Main HTML file with embedded game logic (JavaScript)
style.css    → Stylesheet for layout and design
```

## ▶️ How to Run

1. Clone this repository
   ```bash
   git clone https://github.com/your-username/rock-paper-scissors.git
   ```
2. Navigate to the project folder
   ```bash
   cd rock-paper-scissors
   ```
3. Open `index.html` in any web browser (just double-click the file, or use Live Server in VS Code)

No installation or setup required — it runs directly in the browser.

## 🎮 How to Play
1. Enter your desired target score (default is 5)
2. Click Rock 🗿, Paper 📄, or Scissors ✂️ to make your move
3. The computer makes a random move at the same time
4. The scoreboard updates automatically after every round
5. The game ends once either the player or the computer reaches the target score
6. Click **Reset** or **Play Again** to start a new game
